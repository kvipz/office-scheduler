# Office Scheduler

Tool for planning monthly office attendance — tracks holidays, leave days, WFH days, and planned in-office days for two people, and computes attendance balance for the month.

Live at: https://vip-in-the-cloud.dev/office-scheduler/

The static `docs/index.html` is the standalone version served via GitHub Pages. The repo also contains a Flask app (`app.py`, `core.py`, `templates/`) for running the same calculator locally:

```
pip install -r requirements.txt
python app.py
```
